# ВТОРОЙ КАНОН · Reels «Автоматизм синусового узла»

Вертикальный ролик для @vtoroy.kanon, собранный кодом на Remotion + React + TypeScript.
Все анатомические схемы, графики и анимации нарисованы средствами React/CSS/SVG —
внешних видео- и растровых материалов в ролике нет.

**Тема:** «Почему сердце сокращается само? Автоматизм синусового узла».
**Главная мысль:** сердце не ждёт команды мозга. Синусовый узел сам формирует импульсы,
а вегетативная нервная система лишь меняет частоту их возникновения.

## Результат

| Что | Где |
|---|---|
| Готовый ролик | `output/vtoroy-kanon-sinus-node-reel.mp4` |
| Контрольные кадры | `output/stills/` |
| Дикторский текст и тайминг субтитров | `output/narration-ru.txt` |

Проверено `ffprobe`: H.264 (High profile), 1080 × 1920, 30 fps, 2340 кадров,
78,06 c, pix_fmt `yuv420p` с телевизионным диапазоном, ~3,4 Мбит/с, 31,5 МБ,
плюс беззвучная дорожка AAC (Instagram ожидает наличие аудиопотока).

## Команды

```bash
npm install

npm run dev          # студия Remotion (превью и правка на лету)
npm run stills       # контрольные кадры на 2, 17, 29, 43, 53, 63, 74-й секундах
npm run render:reel  # рендер + финализация в output/vtoroy-kanon-sinus-node-reel.mp4
npm run typecheck    # проверка типов
npm run narration    # перегенерация output/narration-ru.txt
npm run fonts        # пересборка src/styles/fontFaces.ts из public/assets/fonts
npm run noise        # пересборка текстуры зерна public/assets/noise.png
npm run finalize     # только перекодирование готового мастера
```

`npm run stills -- 12 34.5` отрендерит кадры на произвольных секундах.

`render:reel` состоит из двух шагов. Сначала Remotion отдаёт кадры энкодеру
как MJPEG — мастер получается с полным диапазоном яркости (`yuvj420p`) и
битрейтом около 12 Мбит/с. Затем `scripts/finalize-reel.mjs` переводит видео
в `yuv420p` с телевизионным диапазоном, ограничивает битрейт и переносит
moov-атом в начало файла: без этого часть плееров показывает сдвинутые цвета,
а 123-мегабайтный файл незачем ни отдавать в Instagram, ни хранить в git.

## Образ Авиценны

Эталонного файла персонажа в репозитории **нет** — на момент сборки в рабочем каталоге
не нашлось ни одного изображения (`avicenna`, `ibn-sina`, `character`, `assets`,
`references` и т. п.). Чтобы не подменять утверждённый образ случайной картинкой,
`AvicennaCharacter` рисует каноническую графическую фигуру по character bible проекта:
чапан прямого кроя, воротник-стойка, застёжка-Канон у левой ключицы, наручный
измеритель с одной линией пульса, стилус. Лицо не прорисовывается — используется
силуэт в профиль без черт лица.

**Чтобы подключить настоящий эталон:**

1. положите файл в `public/assets/avicenna/avicenna-reference.png`;
2. в `src/data/character.ts` укажите путь:
   ```ts
   export const AVICENNA_IMAGE: string | null = 'assets/avicenna/avicenna-reference.png';
   ```
3. перерендерите: `npm run render:reel`.

Изображение вставляется с `object-fit: contain` и никогда не растягивается.

## Раскадровка

| Сцена | Время | Содержание |
|---|---|---|
| 1 · Крючок | 0–5 c | Один удар в темноте. «Сердце не ждёт команды мозга» |
| 2 · Мозг и сердце | 5–13 c | Нервные связи слабеют — сердце продолжает биться |
| 3 · Синусовый узел | 13–22 c | Камера к правому предсердию, разрез, группа клеток у устья ВПВ |
| 4 · Фаза 4 | 22–37 c | Мембранный потенциал сам идёт к порогу; Iᶠ и кальций T-типа |
| 5 · Фазы 0 и 3 | 37–48 c | Ca²⁺ L-типа даёт подъём, K⁺ — реполяризацию; два цикла подряд |
| 6 · Проведение | 48–58 c | СА → предсердия → АВ-узел (задержка) → Гис–Пуркинье; ЭКГ с P и QRS |
| 7 · Вегетативная регуляция | 58–69 c | Наклон фазы 4 при β₁ и M₂ в одном окне времени |
| 8 · Финал | 69–78 c | «Первый импульс рождается внутри», выходные данные, анонс |

## Физиологические положения, зафиксированные в коде

* У клеток синусового узла нет стабильного потенциала покоя; фаза 4 — спонтанная
  диастолическая деполяризация (`src/data/pacemaker.ts`).
* Iᶠ (HCN-каналы) активируется при гиперполяризации и подписан как **смешанный ток
  Na⁺/K⁺ с результирующим входящим влиянием**, а не как «натриевый ток».
* Позднюю часть фазы 4 поддерживает кальций T-типа, фазу 0 — кальций L-типа
  (быстрые натриевые каналы здесь не главный механизм), фазу 3 — выход K⁺.
* Симпатическое влияние (β₁ → цАМФ ↑) увеличивает наклон фазы 4;
  парасимпатическое (M₂ → цАМФ ↓, gK ↑) уменьшает наклон и делает максимальный
  диастолический потенциал более отрицательным.
* Синусовый узел показан как **группа клеток**; отдельная клетка появляется только
  при переходе к клеточной физиологии.
* Зубец P отнесён к деполяризации миокарда предсердий, а не к самому узлу.
* Сцена 2 не утверждает полной автономии сердца: связь сохраняется, меняется частота.

Перед публикацией материал должен быть сверен медицинским редактором проекта
(«Второй читатель») по редакционному регламенту Второго Канона.

## Технические заметки

* Все анимации зависят только от номера кадра (`useCurrentFrame`), случайных значений
  без фиксированного seed нет — рендер воспроизводим покадрово.
* Плёночное зерно — заранее сгенерированный тайл 160 × 160 (`npm run noise`),
  который сдвигается по номеру кадра. Первая версия использовала полнокадровый
  фильтр `feTurbulence`; в headless-рендере он пересчитывался каждый кадр и
  стоил около 3,5 с на кадр — примерно два часа на весь ролик против нынешних
  двадцати минут.
* Шрифты подключены локально из `public/assets/fonts`; `FontLoader` задерживает рендер
  через `delayRender` до готовности шрифтов, поэтому кадров с подменным шрифтом нет.
* Безопасные зоны: важный текст не ближе 160 px к верхнему и нижнему краю кадра;
  субтитры живут в полосе 1440–1690 px, выходные данные — на 178 px.
* В контейнерах, где уже есть Chromium, `remotion.config.ts` и `scripts/render-stills.mjs`
  используют локальный `chrome-headless-shell`; на обычной машине Remotion скачает
  собственный браузер.
* Озвучки в проекте нет: ролик рассчитан на просмотр с субтитрами. При записи живого
  голоса ориентируйтесь на таймкоды из `output/narration-ru.txt`.
